# GeoFinder2

GeoFinder2 is an AI OSINT tool that finds the location in an image and pins the exact spot on Google Maps.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
